# VideoInstaller 原生桌面版

这里对应 VideoInstaller 当前的原生桌面版来源。普通用户如果只是下载和使用软件，优先使用 GitHub Release 中提供的正式安装包或压缩包即可。

## 版本说明

- 当前推荐下载与使用的都是原生桌面版 `v2.3.0`
- 该版本适用于希望在 Windows 上长期稳定使用的用户
- 如果你没有特殊兼容需求，请优先选择原生桌面版

## 用户说明

- 主页面已经提供“重新自动获取 Cookie”入口，但该能力目前仍不保证每次都成功
- 如果目标站点需要稳定登录态，建议优先按根目录 README 中的说明手动导入浏览器 Cookie
- 安装版更适合长期使用；压缩包版本更适合解压后直接运行
