# 下载与使用说明

本文档用于帮助普通用户选择合适的下载版本，并说明 `v2.3.0` 的当前发布状态。

## 当前推荐版本

当前正式推荐版本为 Windows 原生桌面版：

- `VideoInstaller-v2.3.0-win-x64.zip`
- `VideoInstaller-v2.3.0-win-x64-setup.exe`

## 如何选择下载包

### 如果你想直接解压使用

请选择：`VideoInstaller-v2.3.0-win-x64.zip`

适合希望把程序放在任意目录、下载后立即开始使用的用户。

### 如果你想长期安装使用

请选择：`VideoInstaller-v2.3.0-win-x64-setup.exe`

适合希望通过开始菜单、桌面快捷方式或更接近日常 Windows 软件使用方式来启动程序的用户。

## 当前不提供的版本

- `legacy v2.3.0` 暂不提供下载。
- 原因是该线路当前存在启动后闪退的已知问题，需要修复后再单独发布。

## 使用建议

- 第一次使用时，建议先直接解析一个公开视频，确认程序可以正常打开并完成基础解析。
- 如果遇到登录验证、地区限制或会员内容，建议优先准备浏览器导出的 Netscape 格式 Cookie。
- 如果自动获取 Cookie 失败，可以通过设置页手动导入 Cookie 文件继续使用。

## 安装与更新建议

- 如果你已经在使用旧版本，升级到 `v2.3.0` 后建议先检查下载目录、代理和 Cookie 路径是否符合自己的使用习惯。
- 如果你更关注便携性，可以继续使用 zip 版本；如果你更关注长期稳定使用体验，建议选择安装版。

## 已知事项

- 自动获取 Cookie 目前属于 best-effort 能力，不保证每次都成功。
- `legacy v2.3.0` 当前不提供下载。
