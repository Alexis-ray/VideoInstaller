## VideoInstaller v2.3.0

VideoInstaller v2.3.0 是当前推荐的 Windows 原生桌面版本，重点提升安装后的使用体验，并为需要登录态的网站补充更直接的 Cookie 处理入口。

### 亮点

- 安装版支持在首次安装时设置数据保存位置与下载目录
- 设置页支持更完整的路径调整能力
- 主页面新增“重新自动获取 Cookie”按钮，可在遇到登录态问题时手动再次尝试自动获取
- 桌面版解析结果页中的音频 / 视频格式列表恢复独立滚轮滚动能力
- 安装版的数据保存方式更符合 Windows 常见使用习惯

### 发布资产

#### 原生桌面版（主发布线）

- `VideoInstaller-v2.3.0-win-x64.zip`
- `VideoInstaller-v2.3.0-win-x64-setup.exe`

#### 浏览器兼容版（legacy 保留线）

- `legacy v2.3.0` 暂不上传正式发布资产
- 原因：当前存在“启动后闪退”的已知问题，需要修复后再单独发布

### 说明

- 原生桌面版仍然是当前主发布线
- 压缩包版本适合解压后直接使用；安装版适合长期使用
- 自动获取 Cookie 功能目前仍不保证每次都成功；如果遇到登录验证、地区限制或会员内容，建议按 README 中的说明手动导入 Netscape 格式 Cookie
