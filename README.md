# VideoInstaller

VideoInstaller 是一个本地运行的网页视频下载工具，提供简单直接的浏览器界面，用来解析、下载和整理 YouTube 与 Bilibili 视频资源。

它适合想在自己电脑上快速启动、通过网页界面选择音频或视频格式并保存文件的用户，不依赖数据库，也不需要额外的后端服务。

## 功能

- 支持解析 YouTube 与 Bilibili 视频链接
- 支持选择音频、视频或音视频组合格式进行下载
- 支持将下载结果转码为 H.264 MP4
- 支持下载视频封面
- 支持刷新 `cookies.txt`，便于访问依赖登录态的内容
- 下载结果统一保存到本地 `temp/` 目录

## 运行要求

- Node.js 18 或更高版本
- 当前默认使用方式更适合 Windows 环境

> 如果你所在的网络环境访问外部站点需要代理，可以在 `config.json` 中设置 `proxy`。

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务

```bash
npm start
```

默认情况下，服务会监听在：

```text
http://127.0.0.1:2878
```

启动后会自动打开浏览器，你也可以手动访问上面的地址。

## 使用方法

1. 启动服务并打开页面
2. 粘贴 YouTube 或 Bilibili 视频链接
3. 等待页面解析出可用格式
4. 选择想下载的音频或视频格式
5. 按需要选择直接下载，或下载并转码
6. 下载完成后，从页面提供的链接打开文件或目录

所有下载产物默认会保存到项目根目录下的 `temp/` 文件夹中。

## 配置

项目使用根目录下的 `config.json` 作为运行配置。一个常见的最小示例如下：

```json
{
  "port": 2878,
  "address": "127.0.0.1",
  "tmpDir": "temp",
  "cookie": "cookies.txt",
  "proxy": ""
}
```

常见配置项说明：

- `port`：服务端口
- `address`：监听地址
- `tmpDir`：下载输出目录
- `cookie`：Cookie 文件路径
- `proxy`：访问外部站点时使用的代理地址

## Cookie 说明

如果遇到需要登录后才能访问的视频，可以通过页面中的 Cookie 刷新功能更新 `cookies.txt`，也可以手动准备自己的 `cookies.txt` 文件。

## 注意事项

- 某些视频资源可能依赖有效 Cookie、地区网络环境或账号权限
- 受上游站点策略影响，解析与下载的可用性可能随时间变化
- 本项目更适合本地自用场景
